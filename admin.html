ADMINISTRATION

Manage aisle locations

The admin workspace is the next setup step. To make location changes safely and have them appear for everyone, we need to connect a shared database and secure sign-in.

This starter version intentionally does not store an admin password in the website or pretend that browser-only changes are shared. Once the secure connection is configured, this page will let authorized staff add, edit, and remove brand locations.
